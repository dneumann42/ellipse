# kiwiberry (vendored Nimony port)

`src/kiwiberry/` is a vendored port of <https://github.com/elcritch/kiwiberry>,
a pure-Nim Cassowary constraint solver (based on Kiwi). Upstream targets Nim 2;
this copy is adapted to the Nimony 0.6 language subset and is what ellipse/owl
should import (`import kiwiberry` — already on the `-p:src` path).

Run its tests with `make test` (`tests/kiwiberry_test.nim`, 25 assertions).

## Usage

```nim
import kiwiberry

proc layout() {.raises.} =
  var solver = initSolver()
  let width = vars"width"

  solver[width] = Strong
  solver.constraint(width >= 100)
  solver.suggest(width, 240)
  solver.update()
  # width.value == 240 (as KiwiScalar)
```

## Differences from upstream (Nimony adaptations)

| Upstream Nim 2 | This port |
|---|---|
| `240'ks` literal | plain `240` (int/float64 → `KiwiScalar` converters; Nimony can't bind `static` template params) |
| `UnsatisfiableConstraintError` etc. exception objects with payload fields | `ErrorCode` **values** with the same names (`errors` fragment); payload fields are gone — errors carry no message/object |
| `try: ... except UnsatisfiableConstraintError as e:` | `try: ... except ErrorCode as e:` then compare `e == UnsatisfiableConstraintError` |
| implicit raising procs | explicit `{.raises.}`; the whole solver API is `{.raises.}` (validation + constraint errors) |
| generic DSL (`[A: ConstraintValue]`) | concrete overload matrix generated by `scripts/gen_dsl.nim` into `src/kiwiberry/dsl_generated.nim` (Nimony binds generic bodies eagerly) |
| `lent` accessors | return-by-value accessors |
| `Atomic[uint64]` IDs | plain counter; `internal/assocmaps` uses an `Ordered` concept (Nimony style, like stdlib's `Keyable`) |
| `std/unittest` test files | `tests/kiwiberry_test.nim` with a small `expect`/`expectRaises` harness |
| submodules imported via `import kiwiberry/solver` | fragments **included** into one module: Nimony binds an identifier for each exported module alias, which would collide with `var solver = initSolver()` |

Known Nimony 0.6 workarounds inside the port: whole-object `result[] = value`
ref assignment hits a C-backend bug (avoided in `newSolver`/`reset`), the
3-argument `seq.insert` is missing (manual splice), `solver.constraints` is a
plain `Table` (Nimony's `OrderedTable` is an alias, so constraint iteration
order may differ from upstream dumps).

Error code mapping (documented in `src/kiwiberry/errors.nim`):
`InvalidSolverValueError=ValueError`, `UnsatisfiableConstraintError=RangeError`,
`UnknownConstraintError=KeyError`, `DuplicateConstraintError=AlreadyInProgress`,
`UnknownEditVariableError=IndexError`, `DuplicateEditVariableError=LockedError`,
`BadRequiredStrengthError=OverflowError`, `InternalSolverError=BugError`.
