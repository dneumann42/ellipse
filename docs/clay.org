#+TITLE: clay (Nimony port)

=src/clay/= is a ground-up Nim port of [[https://github.com/nicbarker/clay][clay]] v0.14, the auto-sizing /
floating layout engine for UIs. Upstream is a single-header C library aimed at
the Nim toolchain's macro layer; this copy is adapted to the Nimony 0.6
language subset and is what ellipse should import (=import clay= -- already
on the =-p:src= path).

Run its tests with =make test= (=tests/clay_test.nim=, 54 assertions;
=tests/clay_dsl_test.nim=, 13 assertions covering the plugin DSL end-to-end).
The layout algorithms -- content folding, per-axis grow/percent/compression
passes, word-boundary text wrapping, floating attach-point geometry,
clip/scroll containers with drag + momentum, hover detection and render
command generation -- are ported faithfully, in =float32=, as the C original
computes in =float=. Expected geometries were verified against a ground-truth
harness compiled against the original =clay.h=.

* Usage

The C macro layer (=CLAY(...){...}=, =CLAY_ID=, ...) is not ported as macros.
A Nimony template plugin rewrites =clay= blocks at each call site into
balanced open/configure/close calls, hashing string-literal ids to =uint32=
at compile time:

#+begin_src nim
import clay

proc mono(text: string; cfg: TextConfig): Size =
  Size(width: float32(text.len) * float32(cfg.fontSize), height: float32(cfg.fontSize))

let ctx = initContext(size(800, 600))
ctx.setMeasureText(mono)

ctx.beginLayout()
clay "header", row(gap = 8, padding = padAll(16)):
  ctx.textElement("Hello", TextConfig(fontSize: 24))
  clay col(width = grow()):
    discard
ctx.endLayout()

for cmd in ctx.commands:
  case cmd.kind
  of renderRectangle: drawRect(cmd.box, cmd.fill)
  of renderText:      drawText(ctx.lineText(cmd), cmd.box)
  else: discard
#+end_src

The one-argument form =clay row(...): ...= gets an auto-generated sibling id
(clay's =CLAY_AUTO_ID=). =hashId("label")= computes a standalone id constant
at compile time for queries against last frame's boxes: =pointerOver=,
=elementData=, =scrollContainerData=; =elementId("label")= is the runtime
equivalent, =localId= the =CLAY_ID_LOCAL= equivalent.

* Frame contract

Same shape as clay's own examples:

#+begin_src nim
setPointerState(pos, down)        # reads last frame's boxes
updateScrollContainers(drag, delta, dt)
beginLayout() ... endLayout()     # produces renderCommands()
#+end_src

A single implicit current context backs the no-argument wrappers (for
multi-window apps use =setCurrentContext= or the explicit =ctx= overloads).

* Animations

clay v0.14's transition engine (ghost-cloned exiting subtrees) is
deliberately absent: in immediate-mode Nim animation state usually lives in
the app. Instead keep a =current= value in app state, lerp it towards the
target each frame and write the result into the declaration:

#+begin_src nim
t = min(1.0, t + dt / duration)
let w = lerp(0.0, 250.0, easeOut(t))
clay "sidebar", col(width = fixedPx(w)):
  discard
#+end_src

=lerp= is overloaded for =float32=, =Color= and =Rect=; =easeOut(t) =
1-(1-t)^3=.

* Differences from upstream (Nimony adaptations)

| Upstream C (v0.14)            | This port                                                        |
|------------------------------+------------------------------------------------------------------|
| Arena allocator, max counts  | =seq=/=Table=, generation-stamped stores; no capacity errors     |
|= CLAY(...){...}= macro layer | =clay= template plugin (=src/clay/deps/mclay.nim=)               |
| Designated-initializer decls | Plain objects + factories (=row=, =col=, =grow=, =pct=, =fit=)   |
| Chained =bg=/=border=| Same, as =ElementDeclaration= combinators                        |
|= Clay_ErrorHandler= callback | Errors accumulate; =takeErrors()= drains them after the frame    |
|= double= / =float= mixing    | Everything =float32= (as =clay.h= computes)                      |
| Transition engine            | =lerp= / =easeOut= helpers (see "Animations")                    |
| Separate =clay.h= fragments  | =include=d into one module (Nimony binds an identifier per        |
|                              | imported module alias; =types=/=engine=/=measurement= would be    |
|                              | stolen from host programs -- see the header of =src/clay/clay.nim=) |
